from Mathlib), DONE (kept for the record).

## 3. The triage finding worth keeping

**The cleanest new classical target (Frostman, e1z-1) is Mathlib-blocked, and
the block is a single missing theory: logarithmic potential theory.** Mathlib
today has no capacity, no equilibrium measure, no Green's function, no
subharmonic functions (nearest material: `Complex.AbsMax`). The statement is
typable (the potential $U^\sigma$ is a Bochner integral of $-\log|x-y|$; the
band Green's function has the closed form drafted as `bandGreen`), so a
VERIFIER session could pin the statement, but the proof needs a
potential-theory foundation built or upstreamed first. By contrast the OTHER
three e1z targets and the top of the e1v list are unblocked: the split is
exactly "potential-theory limit statements blocked, finite/variational
statements open for business."

Two small upstream candidates fell out of the triage: `Real.arcosh` (recorded
here as absent; CORRECTED 2026-08-31: `Mathlib.Analysis.SpecialFunctions.Arcosh`
landed upstream 2026-03-23, before the v4.30.0 pin, so the gap claim was stale
at the time of writing and the PR candidate is withdrawn, see
`lean/upstream/arcosh_pr_body.md` DO-NOT-SUBMIT banner) and the finite
Christoffel-variational identity (#VQ-1), which is generic enough for
Mathlib's analysis library.

**#VQ-1a (e1z-2 / e1v-2 kernel), the Cauchy-Schwarz lower bound in product
form** (the Lagrange step carried as the hypothesis `hpair`, house #S4C-2
kernel style):

```lean
theorem christoffel_pairing_lower_bound {M : ℕ} (w c p : Fin M → ℝ)
    (hw : ∀ j, 0 < w j) (hpair : ∑ j, c j * p j = 1) :
    1 ≤ (∑ j, c j ^ 2 / w j) * ∑ j, w j * p j ^ 2
```

with the attainment half `christoffel_pairing_attained` (#VQ-1b) making the
Christoffel minimum exactly $(\sum_j c_j^2/w_j)^{-1}$. Proof route: expand
$0 \le \sum_j w_j (p_j - t c_j / w_j)^2$ at $t = 1/B$, or
`Finset.sum_mul_sq_le_sq_mul_sq`.

**#VQ-2 (e1v-1), Theorem V2 as the existence of the Chebyshev competitor:**

```lean
theorem v2_germ_bound (M : ℕ) (g T : ℝ) (hg : 0 < g) (hgT : g < T)
    (x w : Fin M → ℝ) (hx : ∀ j, g ≤ |x j| ∧ |x j| ≤ T)
    (hw : ∀ j, 0 ≤ w j) (hw1 : ∑ j, w j = 1) :
    ∃ P : Polynomial ℝ, P.natDegree ≤ M - 1 ∧ P.eval 0 = 1 ∧
      ∑ j, w j * P.eval (x j) ^ 2 ≤
        (Real.cosh (2 * (((M - 1) / 2 : ℕ) : ℝ) * bandGreen g T))⁻¹ ^ 2
```

where `bandGreen g T = arcoshReal ((T^2 + g^2) / (T^2 - g^2)) / 2` and
`arcoshReal x = Real.log (x + Real.sqrt (x^2 - 1))` (the recorded
`Real.arcosh` gap; stale, see the 2026-08-31 correction above: Mathlib has
`Real.arcosh` at the pin). This is the Lean face of the e1u-6 discharge.

matrices: `rankOneTransfer u ^ 2 = 0` and the additive degree-one propagator
