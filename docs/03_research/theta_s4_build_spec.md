Both closures name the same next move. The frame audit itself: "the corridor was not wasted: it produced carrier-independent screens (the DMV kill, the divergence theorem, the incommensurability measurement, the Landau translator) that any future S4 candidate must pass" ([`ccm_corridor_frame_audit.md`](ccm_corridor_frame_audit.md) Section 5). ## 2. The chosen candidate, and why this one

Of the three shapes on the table, this spec builds a fusion of (a) and (b): a finite Poisson-summation (Jacobi-theta) kernel, sourced from e1m's own T1b identity (already verified to $<10^{-25}$, measured $\sim 10^{-36}$), rescaled to the general window period $L$ that e1o's carrier uses, and tested for rank collapse at $\{k\log p\}$ with e1o's own instrument, isolated against a wrap-free control so any collapse is attributable specifically to the lattice term rather than to generic kernel smoothness. Option (c), an explicit-formula-side construction, is not chosen as the primary object because it would need to either evaluate the zero side (a K1 violation) or route through exactly the same Mellin/theta bridge (e1m's T1d) that this rung already builds from, at strictly higher construction risk for no discriminating gain at the first rung; its "consume both the Euler product and the lattice" requirement is met anyway, here, because the node set $\{k\log p\}$ only exists as a privileged locus by virtue of the Euler product (Section (c)), and the kernel consumes the lattice by virtue of the theta wrap.

**The two-sentence justification.** This rung is chosen over a literal re-entry into the CCM Sonin space (closed twice over, by falsifier 2 and by today's BBH/Kaltenbäck-Woracek repair search) or a KNS-style density criterion (closed today, frame not collapse, and pre-excluded by the DMV screen regardless) because it is the only candidate in the repo's own record that is simultaneously already machine-verified as a *genuine* lattice identity (not an inequality, so it carries no majorant-style ill-posedness risk: the wrap sum converges absolutely for every $t>0$, unlike the T2a majorant pairing that diverges against the full comb) and cheap to test with an *existing* instrument (e1o's rank/cost-ratio machinery, unmodified in its measurement logic). Its predicted failure mode, if it fails, is informative in exactly the way the disqualifier battery of this whole survey line has trained the project to expect: a nameable, structural wall rather than a silent non-result (Section (d)).

## (a) The object

**The kernel.** For window $L(\lambda) = 2\log\lambda$ (matching e1o's own convention, horizon $p \le \lambda^2 \Leftrightarrow \log p \le L$) and scale $t>0$, define the periodized (wrapped) Gaussian
$$\Theta_t^{(L)}(y) \;=\; \sum_{n=-N_{\mathrm{wrap}}}^{N_{\mathrm{wrap}}} e^{-\pi (y - nL)^2/t},$$
truncated at $N_{\mathrm{wrap}} = N_{\mathrm{wrap}}(\lambda, t)$, chosen so the dropped tail is $<10^{-12}$ relative to the kept sum. This is the direct period-$L$ rescaling of e1m's own T1b identity (`th = lambda t: 1 + 2*mp.nsum(lambda n: mp.e**(-mp.pi*n*n*t), [1,80])` and its shifted form `sum_n e^{-pi(n+x)^2 t}`, verified there to worst-case defect $<10^{-25}$, measured $\sim1.5\times10^{-36}$): substituting $t \to t/L^2$, $x \to y/L$ gives the dual (Poisson) representation
$$\Theta_t^{(L)}(y) \;=\; \frac{\sqrt t}{L}\sum_{k=-K_{\mathrm{wrap}}}^{K_{\mathrm{wrap}}} e^{-\pi k^2 t/L^2}\cos(2\pi k y/L),$$
which BUILDER verifies to the same tolerance class ($<10^{-25}$) before using either form; this is Phase 0 below.

**The node sets.** $X_\lambda = \{\log p : p \text{ prime},\ p \le \lambda^2\}$ (e1o's exact log-prime comb, size $M(\lambda) = \pi(\lambda^2)$), at the same lambda grid e1o used, $\lambda \in \{2.2,\ 3.0,\ \sqrt{13},\ 6.0\}$, for direct numeric comparability with e1o's own baseline (ratio $1.000$ everywhere on this grid). The Beurling twin $X_\lambda^{\mathrm B}$ is `BeurlingSystem(prime_bound >= ceil(lambda**2), eps=0.25, seed=149).logs` restricted to $\le \log(\lambda^2)$ (matched density by construction, the repo default fake).

**The matrices.** For each $(\lambda, t)$ cell, with nodes $x_1 < \cdots < x_M$ (zeta or Beurling):
$$G_{jk}(t) = \Theta_t^{(L)}(x_j - x_k), \qquad G^{(0)}_{jk}(t) = e^{-\pi(x_j-x_k)^2/t}$$
($G^{(0)}$ is the $n=0$-only, wrap-free control: a generic Gaussian Gram matrix carrying no lattice input at all, the same "generic trig/PW carrier" territory e1o's Q3(a) already measured content-free). $G - G^{(0)}$ is the part attributable specifically to $\sum_{n\ne0}$, i.e. specifically to the additive lattice $L\mathbb{Z}$.

**Data consumed.** Only primes (via $X_\lambda$, an Euler-product-carried locus) and the integers $\mathbb{Z}$ (via the wrap sum, an additive-lattice-carried object). No zeta zero location, at any step (Section (c)).

## (b) The tests

Three phases, each a genuine falsifier, following the discipline set by [`c1_joint_build_spec.md`](c1_joint_build_spec.md) Section (b): both outcomes at each phase are informative, not pre-destined to grade UNMOVED.

**Phase 0. The anchor: generalize, then re-verify.** Before any rank claim means anything, confirm the rescaled dual identity to the same class of precision e1m achieved at $L=1$: compute both sides of $\Theta_t^{(L)}(y) = (\sqrt t/L)\sum_k e^{-\pi k^2t/L^2}\cos(2\pi ky/L)$ at $L = L(\lambda)$ for each tested $\lambda$, at 3-5 representative $(y,t)$ pairs spanning the grid below. **Pass**: max relative defect $<10^{-25}$ (e1m's own T1a/T1b bar), $N_{\mathrm{wrap}}, K_{\mathrm{wrap}} \le 80$ (matching e1m's own truncation). **Fail**: the identity does not transport cleanly to general $L$ at high precision, an earlier, narrower wall than Phase 1, recorded the same way c1's own Phase 0 would be.

**Phase 1. The collapse test (the S4 question itself), zeta side.** For each $\lambda$ in the grid and $t$ swept over a geometric range from the minimum pairwise gap squared in $X_\lambda$ up to $L(\lambda)^2$ (8-10 points, log-spaced; BUILDER's choice, analogous in spirit to e1o's own $\delta \in \{4,8,16,32,64\}$ sweep), compute $G(t)$ and $G^{(0)}(t)$, their numerical ranks at relative singular-value threshold $10^{-8}$ (e1o's own T4c convention exactly), and
$$\rho(\lambda,t) = \mathrm{rank}_{10^{-8}}(G(t))/M(\lambda), \qquad \rho^{(0)}(\lambda,t) = \mathrm{rank}_{10^{-8}}(G^{(0)}(t))/M(\lambda), \qquad \Delta\rho = \rho^{(0)} - \rho.$$
Report, at the declared rank $r$ of $G(t)$, the conditioning pair $\sigma_r/\sigma_1$ and $\sigma_{r+1}/\sigma_1$ (e1o's own "min sv 0.08-0.98" discipline, built to catch the superresolution mirages its adversary round found in the near-commensurate decimation family). **Positive discovery**: some cell with $\Delta\rho \ge 0.1$, a genuine spectral gap ($\sigma_r/\sigma_1 > 10^{-3}$, $\sigma_{r+1}/\sigma_1 < 10^{-6}$), and $\Delta\rho$ non-shrinking across the two largest tested $\lambda$ (the lambda-uniformity check, condition (3)). **Predicted wall**: $\Delta\rho \approx 0$ at every cell (both $G$ and $G^{(0)}$ track e1o's own $\rho^{(0)}\text{(no-wrap)}\approx\rho\text{(zeta baseline)} = 1.000$ together), or a nonzero $\Delta\rho$ that fails the conditioning gate (a smooth tail, the mirage e1o's adversary already caught once in this family) or shrinks with $\lambda$.

**Phase 2. The disciplines, in the same run.** Beurling twin: rerun Phase 1's exact battery on $X_\lambda^{\mathrm B}$ at matched $(\lambda,t)$ cells; separately, rerun Phase 0's dual-identity check with $\mathbb{Z}$ replaced by `BeurlingSystem`'s own generalized integers in the wrap sum (the direct analogue of e1m's T5, predicted defect of order $0.1$-$1$, by direct analogy to T5's measured $0.37$). D-H: cited, not re-run (Section (c)). K1: guards + `consume()` ledger (Section (c)).

## (c) The disciplines

**Beurling.** Two independent nameable-failure sites, either sufficient. (i) The kernel's *own defining identity* (the dual/Poisson representation) is built from $\mathbb{Z}$ specifically; substituting the Beurling system's generalized integers into the same wrap sum breaks the closed dual form (predicted defect $\gg 10^{-25}$, by direct analogy to e1m's T5 measurement of $0.37$ for the un-rescaled case): the construction cannot be built the same way for the fake, a failure at the construction step, not merely the measurement step. (ii) Even granting the fake a same-shaped kernel built from true $\mathbb{Z}$ but evaluated at the fake's scattered node set $X_\lambda^{\mathrm B}$ (the more direct e1o-style twin, matching how e1o's own T3 ran the *identical* machinery on the fake rather than rebuilding it), Phase 2 requires the collapse gap $\Delta\rho$ measured on $X_\lambda^{\mathrm B}$ to be at most half of zeta's, at matched cells; if it is not (if the twin collapses just as well), the mechanism is system-generic in exactly the sense the DMV kill forbids, and this must be recorded as a genuine, load-bearing negative regardless of Phase 1's zeta-side outcome, per the discipline's own rule ("not satisfied by a check literally erroring; satisfied by naming which clause fails").

**Davenport-Heilbronn.** Unposable, by two independent, already-established arguments, cited rather than re-derived. (i) AX-FORM: the construction's node set $X_\lambda$ exists only because zeta has an Euler product (prime powers are a privileged locus); D-H has no Euler product, so its coefficient comb is dense and sign-changing over all $n$ (e1o T5a: 25 sign changes below $n=60$; negative excess exhibit $-0.288$), with no privileged prime-power sublattice to test the kernel against, the same Euler gate [`landau_one_sided.md`](landau_one_sided.md) names for the Landau translator. (ii) Type exclusion: the kernel is built around the conductor-1, trivial-character theta sum (matching zeta's own $\Gamma(s/2)$ gamma factor); e1m's T2 measured that D-H's own FE is exact (defect $1.7\times10^{-30}$) but a Riemann-type (conductor-1) reconstruction fails at $O(1)$ (defect $1.72$, budget surplus $20.7$ zeros at $T=85.699$), so even forcing D-H's coefficients through this specific kernel would be testing the wrong conductor. Both hold regardless of Phase 1's outcome; no D-H numeric rerun is required, matching the exemption precedent in [`c1_joint_build_spec.md`](c1_joint_build_spec.md) Section (c) and CLAUDE.md's Architecture-2-style carve-out.

**K1 guard.** No `mp.zetazero`, no fitted $\gamma_n$, no zero list or zero-scanner token, at any construction or test step in Phase 0, 1, or 2. Inputs are exhaustively: primes/prime-powers up to $\lambda^2$ (Euler-product data), the integers $\mathbb{Z}$ or the Beurling generator logs (additive/twin data), and the scale grid $t$ (a free parameter, not arithmetic data). Reuse the `consume(test, *inputs)` ledger-printing convention shared verbatim by `e1m_hamburger_pin.py` and `e1o_s4_carrier.py`, and install runtime guards on `mp.zetazero` and the D-H zero scanner (e1o T5b/c's pattern), asserted never tripped.

## (d) The grading

Four checks, not three, because a rank-collapse claim on this family carries an extra failure mode (the conditioning mirage) that c1's ghost/THH context did not need to guard against; read together they replace c1's three-tier scheme with the same spirit.

1. **Lattice-genuine collapse (the S4 bar, Q4 condition 2 actually met).** A cell passing all of: wrap-attributable ($\Delta\rho \ge 0.1$, present in $G$, absent in $G^{(0)}$ at the same $t$), well-conditioned (a genuine singular-value gap, not a smooth tail, i.e. not the mirage e1o's own adversary round already caught once in the near-commensurate decimation family), lambda-uniform (non-shrinking across the tested grid), and Beurling-separating (the twin's $\Delta\rho$ at most half of zeta's at matched cells). All four required.
2. **Measured but partial.** A gap appears and clears some but not all of the four (for instance well-conditioned and wrap-attributable at one $\lambda$ but shrinking at the next, or present but only mildly separated from the Beurling twin). Recorded as a genuine partial finding, the e1p "measured profile, not a theorem instance" bar, not the S4 spec itself.
3. **Blind / mirage / fail.** No gap at any tested cell ($\Delta\rho \approx 0$ throughout, both matrices tracking e1o's own full-price baseline together), or a gap that fails the conditioning gate, or Phase 0's identity fails to generalize to $L(\lambda)$ (an earlier, narrower wall).
4. **System-generic (a distinct failure mode from 3, tested only in Phase 2).** A gap that clears the Phase-1 conditioning and uniformity checks but reproduces at matched strength on the Beurling twin: the mechanism would then be genuinely collapsing, but for a lattice-agnostic reason invisible to this test design, exactly the DMV-kill trap the discipline exists to catch. This must be reported even though it is a "positive" rank result, because per the DMV kill any mechanism whose inputs are density/generic-kernel-only is pre-killed at every exponent below 1 regardless of the collapse measurement.

**The pre-registered wall statement.** The single most likely result, stated in advance: Phase 1 finds $\Delta\rho \approx 0$ at every tested $(\lambda,t)$ cell, i.e. the wrap-around (lattice) correction to a generic Gaussian kernel is too small (Gaussian-suppressed at the scales where $G^{(0)}$ is still well-conditioned) or, where nonzero, ill-conditioned (a smooth tail) to produce a genuine collapse, extending e1o's own five-family-hardened absence (T4c's adversary round) to a sixth, this time genuinely lattice-consuming, family. If this is what happens, the honest reading, following the project's stance on negative results as coordinates rather than dead ends, is sharper than a repeat of the prior walls: it would show that even a construction that *provably* consumes the additive lattice (unlike KNS's density-only criterion, unlike raw trig decimation, unlike the closed majorant route) still cannot produce a well-conditioned collapse at $\{k\log p\}$ using the *simplest* available lattice-consuming device, a bare periodized Gaussian. That narrows the missing mechanism one notch further: it would not be "any construction that consumes the lattice," but specifically one that ties the additive lattice to the *multiplicative* (Euler-product) structure nontrivially, which points concretely at the one genuinely unexplored corner the frame audit itself flagged as having zero repo mentions, the Cohn-Elkies/Viazovska/Radchenko-Viazovska modular-interpolation corpus (genuine modular forms and Hecke structure, not a bare theta function), as the next rung rather than a fresh survey. A positive Phase 1 result (tier 1), by contrast, would feed directly back into [`landau_one_sided.md`](landau_one_sided.md)'s BRIDGE-H/R1 mechanism question: cheap multiplicity at $\{k\log p\}$ is exactly what would let the Stepanov pairing run linearly instead of quadratically, deleting the sieve's level-halving 2 (Q4's own stated payoff).
